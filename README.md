# EVENTORA — Bespoke Event Management Landing Page

A modern, responsive, and luxury landing page for **EVENTORA**, a bespoke event management and live production company.

## ✨ Features

- **Hero Showcase**: High-impact event photography, compelling headline, and dual call-to-actions.
- **About Agency**: Introducing EVENTORA's narrative, illustrative metrics, and core pillars.
- **Signature Services**: 6 discipline cards with icons, highlights, and prefilled inquiry triggers.
- **Featured Events**: Filterable portfolio grid (Weddings, Corporate, Concerts, Celebrations) with detailed showcase modals.
- **Why Choose Us**: 6 core agency standards with balanced icon layouts.
- **Our Process**: 4-step interactive event curation workflow timeline.
- **Client Endorsements**: Testimonials with star ratings and client roles.
- **Call-to-Action**: High-converting banner with smooth scroll navigation.
- **Contact & Consultation**: Frontend-only inquiry form with client-side validation and demonstration modal.
- **Footer**: Brand statement, quick links, newsletter form mock, and social channels.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS 3.4
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Fonts**: Plus Jakarta Sans & Playfair Display

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
npm run preview
```
